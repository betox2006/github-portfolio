What is CSS?

CSS (Cascading Style Sheets) is the code that styles web content. CSS basics walks through what you need to get started. We'll answer questions like: How do I make text red? How do I make content display at a certain location in the layout? How do I decorate my webpage with background images and colors?

Like HTML, CSS is not a programming language. It's a style sheet language. For example:

p { color: red; }

Anatomy

The whole structure is called a ruleset. Note the names of the individual parts:

  • Selector: The HTML element name at the start of the ruleset. E.g., p.
  • Declaration: A rule like color: red;.
  • Properties: Ways to style the element.
  • Property value: The value of the property (e.g., red).

Example:

p {
  color: red;
  width: 500px;
  border: 1px solid black;
}

Fonts and text

Add Google Fonts to your <head>:

<link href="https://fonts.googleapis.com/css?family=Open+Sans" rel="stylesheet">

Set global font-size and font-family:

html {
  font-size: 10px;
  font-family: "Open Sans", sans-serif;
}

Set heading and text styles:

h1 { font-size: 60px; text-align: center; }
p, li { font-size: 16px; line-height: 2; letter-spacing: 1px; }

CSS: all about boxes

CSS layout is based on the box model. Properties include:

  • padding, border, margin, width, background-color, color, text-shadow, display

Example:

html { background-color: #00539f; }

Styling the body

Example CSS:

body {
  width: 600px;
  margin: 0 auto;
  background-color: #ff9500;
  padding: 0 20px 20px 20px;
  border: 5px solid black;
}
